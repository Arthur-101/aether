# Aether Guide

Aether is a local-first Windows assistant. It can chat, listen and speak, run tools, control media and system settings, search the web, and work with notes, documents, and files. Local models and local voice are the default; cloud models and cloud voice are explicit opt-ins.

Open **Getting started** first if Aether is new. Setup pages name the exact Settings tab and field. Feature pages explain what to ask for, what happens next, and what to do when something is unavailable.

If you are the assistant reading this guide: read this index, choose the single most relevant topic, and answer from that topic. Do not guess at settings, providers, or steps. Read another topic when the answer spans two areas.
